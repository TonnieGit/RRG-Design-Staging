Design Rationale — Config-Variant Template

Decisions

The variant picker is two comparison cards, not a dropdown — both price and a one-line trade-off note ("ready to fit" vs "flat pack, save $169, self-assembly") are visible before the user even clicks, so the price-vs-convenience decision (this template's core conversion challenge) can be made by scanning, not by opening a menu and reading each option in isolation. Selecting a card live-updates gallery, video (Assembled only), price, specifications and the Fitting Instructions link — everything variant-aware per the data model, nothing needs a page reload.

Grounded in

Section 1 table (config-variant's stated challenge: "making the trade-off... clear and easy to compare"); Section 0.1.6 (thumb-friendly variant selectors on mobile, not a cramped native dropdown — these are large tap targets, not a <select>); Section 1.2 of the requirements doc (variant swap must cover price, video presence, and Fitting Instructions PDF, confirmed here).
